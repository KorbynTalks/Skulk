# Skulk
Skulk is a Minecraft Indev 20100223 Mod made with Ornithe. It aims to fix bugs and issues that annoyed me when playing.
## [![Skulk On Modrinth](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/compact/available/modrinth_vector.svg)](https://modrinth.com/mod/skulk-korbyntalks) [![Skulk On CurseForge](https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/compact/available/curseforge_vector.svg)](https://www.curseforge.com/minecraft/mc-mods/skulk)

Main stuff are:
* Improved Mouse Behavior
* Background Music not fading out after traveling some distance
* Quit Game buttons on Main Menu and Pause Menu
* Using Betacraft Proxy to download Resources.
* and potentially more to come.

Compatibility with other mods not gaurenteed 👍
